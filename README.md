# Universe Explorer 🌌

Explore the universe from your phone or computer using the original interactive WebGL explorer.

**Website:** https://bill6006.github.io/Universe-Explorer/

## Add to your Android home screen

Open the website in Chrome, tap **⋮**, then choose **Add to Home screen** or **Install app**.

## Features

- Zoom and explore planets, moons, other stars, and galaxies
- Responsive touch controls and a guided tour
- Standalone home-screen shortcut with a custom icon

The site needs WebGL 2 and network access to load 3D modules and astronomical textures from third-party hosts. The imagery credits remain visible in the experience.

## Publishing

Pushing to `main` deploys the site with GitHub Actions / GitHub Pages.
